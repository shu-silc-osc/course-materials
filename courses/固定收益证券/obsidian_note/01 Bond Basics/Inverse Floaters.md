# Inverse Floaters

## 核心定义

Inverse floater 的 coupon rate 与 reference rate 反向变动。

```
Coupon Rate = K - L × Reference Rate
```

其中：

- K 是设定的最高基准
- L 是杠杆倍数
- reference rate 上升，coupon 下降
- reference rate 下降，coupon 上升

## 投资含义

Inverse floater 适合预期利率下降的投资者，因为利率下降会提高 coupon。

## 风险

- coupon 可能快速下降
- 价格对利率更敏感
- 结构可能带有 floor，避免 coupon 变成负数
